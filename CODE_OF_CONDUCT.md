# Code of Conduct

Theophylax adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all project spaces — issues, pull requests, discussions, reviews and any community channel — and when someone represents the project elsewhere.

In short: be respectful and constructive, assume good faith, critique ideas rather than people, and make it easy for newcomers to take part. Harassment, discriminatory language, personal attacks and publishing other people's private information are not acceptable.

## Reporting

Report conduct concerns privately to the maintainers by email at **anirudh.koutha@gmail.com**. Reports are handled confidentially. If a report concerns a maintainer, that maintainer will not take part in handling it.

Security vulnerabilities are not conduct issues; report them as described in [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers review every report and decide on a response following the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines), from a private correction through to a temporary or permanent ban, depending on the severity and pattern of behaviour.
