Theophylax is an AI gateway that sits between your people, apps and agents and the models they use. Claude Code, Codex CLI and the Anthropic and OpenAI SDKs work unchanged, across Anthropic, AWS Bedrock, Google Vertex AI, Azure and any OpenAI-compatible endpoint.

Protect

Secrets are swapped for placeholders before any model sees them, and policy is enforced on every prompt, tool result and response.

Control

Decide who can call which models, through which providers, at what cost, with budgets, rate limits, routing and failover.

Prove

Every request gets an Ed25519-signed receipt that anyone can verify offline, anchored in a hash-chained audit log.

Try it in one command

Postgres and the gateway, with a mock model and demo data. No provider credentials needed.

git clone {{.RepoURL}}.git theophylax && cd theophylax
docker compose -f deploy/compose/docker-compose.yml up --build
# open http://localhost:8080 and sign in as admin@example.com / change-me-please

Then point Claude Code at it:

export ANTHROPIC_BASE_URL=http://localhost:8080
export ANTHROPIC_AUTH_TOKEN=tpx_…   # create one under API keys
claude

What makes it different

Proof-of-Inference receipts

Signed receipts record who called, digests of the exact request and response, where the request was routed, which guardrail versions applied and what it cost. They contain no prompt content. Receipts · spec

Secret Shield

Cloud keys, tokens, private keys and connection strings are replaced before the model sees them, and optionally restored in the response, streams included. Guardrails

Prompt-injection defence

In-process, multi-layer detection: de-obfuscation, smuggled characters, encoded payloads and indirect injection through tool results. It is measured in the open against a committed corpus. How well it works

Eval-gated rollouts

Shadow a new model on live traffic and let a judge compare its answers with the current model's. Then canary it and promote or roll back automatically. Rollouts

Responses API on Claude

Codex CLI and the OpenAI Agents SDK run on Claude through Bedrock, Vertex, Foundry or Anthropic, translated by the gateway. API reference

Enterprise identity, included

OIDC SSO, SCIM, roles across orgs, teams and projects, audit logs and Prometheus metrics, with nothing held back for a paid tier. Identity
